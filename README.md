## ## 01. Классификатор обращений

Скрипт для автоматического разбора и классификации входящих обращений на три категории: `справка`, `жалоба` и `другое`.

### ### Как запустить
1. Убедитесь, что файлы `classify.py` и `messages.txt` находятся в одной папке.
2. Запустите скрипт через терминал:
   ```bash
   python classify.py
   ```

### ### Что получилось (Результат работы)
Скрипт успешно считывает файл, определяет категорию на основе правил фильтрации текста и генерирует базовый шаблон ответа на русском языке. Все 5 тестовых обращений успешно категоризированы.

## ## 02. Фильтр алертов

Скрипт для фильтрации шума в системных логах и выявления критических инцидентов.

### ### Как запустить
1. Убедитесь, что файлы `events.json` и `filter_alerts.py` находятся в одной папке.
2. Запустите скрипт через терминал:
   ```bash
   python filter_alerts.py
   ```

### ### Что получилось (Результат работы)
Скрипт отфильтровал 8 исходных событий, вывел в консоль только 3 критические ошибки (`disk 90%`, `payment failed`, `db timeout`) и напечатал обязательную финальную строку summary: `критичных 3`.
